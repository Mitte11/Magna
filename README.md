# Magna

Magna is an offline-first manga and manhwa downloader and reader for Windows.

## Download

Download the latest Windows installer from the [Releases](https://github.com/Mitte11/Magna/releases) page.

## Features

- MangaDex, MangaFire, and WEBTOON support
- Chapter downloads and offline reading
- Language and scanlation group filters
- Automatic updates through GitHub Releases
